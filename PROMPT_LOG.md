Prompt Log — Dashboard Ejecutivo y Modelo BI
1. Objetivo del uso de IA

Se utilizó ChatGPT como herramienta de apoyo durante la elaboración de la pre-entrega de Dashboard Ejecutivo y Modelo BI en Excel.

El objetivo fue recibir orientación paso a paso para la preparación de los datos, el modelado en Power Pivot, la creación de medidas DAX, la construcción del dashboard y la configuración de elementos interactivos.

2. Prompts y asistencia utilizada
Preparación y validación de datos
Se solicitó ayuda para interpretar la consigna y organizar los pasos necesarios para completar la actividad.
Se consultó cómo implementar validaciones de datos en Excel, incluyendo una lista desplegable para la categoría de productos.
Se consultó cómo estructurar las tablas necesarias para el modelo BI.
Power Query y modelo de datos
Se solicitó orientación para cargar los datos mediante Power Query.
Se consultó cómo incorporar las tablas al Modelo de datos de Excel.
Se verificó la relación entre las tablas Ventas y Productos mediante el campo ID_Producto.
Se utilizó Power Pivot para revisar el modelo y comprobar que la relación entre las tablas estuviera activa.
Medidas DAX

Se solicitó ayuda para crear y comprender medidas DAX destinadas al análisis de los datos.

Las medidas utilizadas fueron:

Ventas Totales
Margen Neto
Margen %
Transacciones

También se consultó cómo utilizar estas medidas dentro de tablas dinámicas y del dashboard.

Dashboard
Se solicitó orientación para organizar los indicadores principales del dashboard.
Se incorporaron cuatro indicadores: Ventas Totales, Margen Neto, Tasa de costo y Margen %.
Se utilizaron gráficos para visualizar las ventas por período, cliente y producto.
Se incorporaron segmentadores para facilitar el análisis interactivo.
Interactividad

Se solicitó ayuda para configurar:

Segmentador de Meses.
Segmentador de Producto.
Línea de tiempo basada en Fecha.
Conexión de los segmentadores y la línea de tiempo con los distintos gráficos del dashboard.

Se verificó que los filtros modificaran los gráficos de manera conjunta.

Presentación

Se solicitó orientación para mejorar la presentación ejecutiva del dashboard.

Como parte de esta etapa se ocultaron:

Líneas de cuadrícula.
Encabezados de filas y columnas.
3. Resultado

La asistencia de IA se utilizó principalmente como apoyo técnico y educativo. Las decisiones sobre la organización final del archivo, los datos utilizados y la presentación del dashboard fueron realizadas durante el desarrollo de la actividad.

El resultado final es un archivo Excel que integra datos, Power Query, Modelo de datos, relaciones entre tablas, medidas DAX, indicadores, gráficos y elementos interactivos.
